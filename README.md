# 🧾 Receipt Splitter

### AI-Powered Receipt Scanner & Smart Bill Splitter

[🚀 Live Demo](https://receiptsplitter-jdx7hmrxn8q56vdewyjmmm.streamlit.app/)

An AI-powered receipt scanning and bill-splitting web application built with Streamlit and Google Gemini.

## 🚀 Live Demo

https://receiptsplitter-jdx7hmrxn8q56vdewyjmmm.streamlit.app/

## ✨ Features

- Upload a receipt image
- AI-powered receipt scanning using Gemini
- Extract store name, items, quantities, prices, tax, discount and total
- Add multiple people to the bill
- Select who shared each item
- Automatically calculate each person's share
- Distribute tax and discounts proportionally
- Verify the calculated amount against the receipt total
- Generate a friendly WhatsApp message
- Share the final bill through WhatsApp

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini
- Google GenAI SDK
- WhatsApp sharing

## 🔄 How It Works

1. Upload a receipt.
2. Gemini analyzes the receipt.
3. Add the people sharing the bill.
4. Select who shared each item.
5. The app calculates everyone's share.
6. Tax and discounts are distributed automatically.
7. Generate a WhatsApp message with the final split.

## 🎯 Purpose

Receipt Splitter makes splitting restaurant, shopping, and group bills faster and easier by combining AI-powered receipt understanding with automatic calculations.
